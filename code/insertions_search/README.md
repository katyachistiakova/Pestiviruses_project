## Поиск вставок в белковых выравниваниях

Этот скрипт на Python позволяет:
1. Находить вставки в белковых выравниваниях (FASTA)
2. Определять их расположение по координатам выравнивания и относительно белковых доменов
3. Создавать сводку и отдельный FASTA файл с найденными вставками. 
4. Выполнять кластеризацию вставок и поиск наиболее вариабельного региона.

---

## Особенности

- Поиск вставок, длиннее минимального порога (`--min_len`), с учетом доли гэпов (`--gap_thr`) в колонках выравнивания.  
- Сохранение вставок в отдельный FASTA файл с описанием позиции относительно доменов и длины.  
- Кластеризация вставок и идентификация наиболее вариабельного региона.  
- Поддержка файлов доменов и HMM (опционально).  

---

## Установка

1. Установите Python ≥ 3.8  
2. Установите зависимости:

```bash
pip install biopython numpy
```

## Использование

Базовый запуск:
```python insertions_search.py -i input_alignment.fasta -o_f all_insertions.fasta -o_s insertions_summary.tsv
```

Дополнительно:

--min_len: минимальная длина вставки (по умолчанию 3)
--gap_thr: порог доли пробелов для выявления вставки (по умолчанию 0.7)
--domains: путь к файлу с доменами (опционально)
--hmm: путь к HMM файлу (опционально)

Пример запуска с HMM и порогом:
```python insertions_search.py -i input_alignment.fasta -o_f all_insertions.fasta -o_s insertions_summary.tsv --min_len 3 --gap_thr 0.8 --hmm profiles.hmm
```

## Выходные файлы

all_insertions.fasta — FASTA файл с найденными вставками. Описание каждой последовательности содержит: длину вставки и позицию в выравнивании.
insertions_summary.tsv — TSV файл со сводкой:
aln_start — начальная позиция вставки
aln_end — конечная позиция вставки	
length — длина вставки
Также содержит информацию о кластерах вставок и наиболее вариабельном регионе.

## Примечания

Скрипт не изменяет исходное выравнивание.
Файлы доменов и HMM используются для дополнительной информации, но анализ вставок возможен без них.
Порог gap_thr зависит от количества последовательностей в выравнивании и от цели поиска вставок (найти редкие уникальные вставки или вариабельные регионы).
